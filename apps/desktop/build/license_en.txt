4. Credentials and local data
-------------------------------------------------------------------------------
E Agent encrypts stored API keys according to its configuration, but you must
still use least-privilege credentials, rotate them, and secure the device. A
normal uninstall keeps local conversations, settings, plugins, and encrypted
credentials by default. The uninstaller lets you explicitly choose permanent
removal; back up required data first because E Agent cannot restore deleted data.
